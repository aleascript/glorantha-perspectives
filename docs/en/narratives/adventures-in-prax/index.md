# Adventures in Prax

Alongside [**The Lunar Way**](../the-lunar-way/), the adventures of [**Peek-ee-Peek**](../the-lunar-way/heroes/peek-ee-peek/) in Prax.

Peek is the same Protagonist as in *The Lunar Way*, but these games use the current Glorantha Perspectives rules and form an independent series.

When a **Verbatim** is strong enough to carry the story, it is published as played rather than systematically rewritten into prose. Likewise, every game does not need a Debrief or a new Portrait: those documents exist only when they genuinely add something.

- [**The Three Stones Spring**](three-stones-source/) — a Praxian spring, a Lunar construction project, and a full-moon night.
