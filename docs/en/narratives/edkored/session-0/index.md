# Session 0 — Breath and Lightning

This first published session is the **entry point of Edkored's chronicle**.

Sorane warns Edkored that a Tarshite patrol is threatening an old Kolati shaman. After drawing the soldiers away with Hedkoranth's lightning, Edkored follows a sign from Orlanth to Still Lake. There he finds Vorlak, a badly wounded young Mudhen, and refuses to let him die.

The session ends in a boat, travelling toward Orstalor Spearlord's hidden crannog.
