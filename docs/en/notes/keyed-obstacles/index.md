# Keyed obstacles — design track (WIP)

> This note is not part of the published *Glorantha Perspectives* rules. It preserves a game-design track removed from the Guide so it can be reconsidered separately.

## Removed design track

An earlier version of *Glorantha Perspectives* proposed special handling for some Situations that are not only about overcoming resistance, but about understanding **what must be gathered or discovered before the problem can be solved**.

An investigation, puzzle, complex craft, or repair could therefore be described through several **keys**.

Examples:

- an investigation: *the culprit*, *the motive*, *the method*;
- an alchemical preparation: *a usable laboratory*, *the right ingredients*, *the correct recipe*.

Keys were meant to be truths of the Situation rather than boxes that had to be checked in a fixed order.

The Protagonists could obtain some of them directly through their choices and searches when nothing made their acquisition uncertain. When genuine uncertainty appeared, normal resolution applied.

The former rule also stated that the number and nature of missing keys could help define the opposition or a Frame Factor. **That relationship is no longer canonical** and is part of what must be redesigned.

Finally, a discovery could reveal that the original keys were incomplete or misunderstood. In that case, the description of the problem was meant to change rather than preserve a secret structure that had become false.

## Current state of the Guide

The Guide currently contains **no special mechanic for keyed obstacles**. An investigation, puzzle, craft, or repair uses the ordinary principles of Situation, Intention, Focus, Zoom, Frame Factors, Bets, and resolution until a dedicated design has been consolidated.

## To revisit

The design intention behind keys is not abandoned. It should be revisited in a dedicated conversation with the author, starting from what this structure was actually meant to produce in play rather than treating the historical implementation as a specification.
