# Scripts — design track (WIP)

> This note is not part of the published *Glorantha Perspectives* rules. It preserves a game-design track removed from the Guide so it can be reconsidered separately.

## Current state of the Guide

In the current rules, **Script** follows the Regard definition: it is a **broad Zoom**. The Focus may cover a journey, investigation, military campaign, prolonged negotiation, or complex project.

A Script reveals more relevant dimensions because the question asked of the fiction is broader. It does not, by itself, add a special procedure.

## Removed design track

An earlier version of *Glorantha Perspectives* gave Scripts an additional structure:

- a Script was described as a known series of steps leading toward a result — for example several ritual trials, a prepared operation, a Heroquest structured by a myth, or a complex procedure;
- the main steps were named before the roll;
- the Bets relevant to getting through the Script as a whole were gathered into one resolution;
- if the outcome sought by the Protagonists did not prevail, their number of Successes could help locate how far they got before the plan broke;
- in some Situations, one Success could correspond to one completed step;
- if the sought outcome prevailed, the Script reached its end and the quality of the result together with the Bets showed how.

This mechanic is **no longer canonical**. It introduces Script-specific behaviour that does not follow from the current definition of Zoom and must be redesigned before any reintegration.

## To revisit

The design intention behind this structure is not abandoned. It should be revisited in a dedicated conversation with the author, starting from the play problem this design was meant to solve rather than treating the historical implementation as a specification.
