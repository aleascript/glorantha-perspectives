# Un monde marqué par les Runes

Dans Glorantha, les Runes ne sont pas seulement des symboles abstraits. Elles donnent forme au monde et peuvent devenir visibles dans les personnes, les objets, les bâtiments et les paysages.

Il n'est pas nécessaire de savoir interpréter toutes les Runes pour jouer. Commencez simplement par remarquer que Glorantha peut montrer ce qu'elle est.

## Couleurs runiques

Une affinité forte peut apparaître dans la peau, les yeux, les cheveux, les vêtements, les matériaux ou les effets magiques.

Quelques associations utiles :

- **Air** : orange ou bleu ;
- **Terre** : vert olive ou marron ;
- **Lune** : rouge ou blanc ;
- **Eau** : bleu ou blanc ;
- **Obscurité** : gris terne ou noir ;
- **Feu/Ciel** : jaune ou rouge.

Ces marques peuvent être présentes depuis la naissance, apparaître à l'initiation, se renforcer pendant une cérémonie ou changer après une Quête héroïque.

Ces correspondances sont des repères, pas un code universel. Les cultures peuvent rendre une même Rune visible de manières différentes.

## Formes runiques

Les formes elles-mêmes peuvent rappeler les Runes : architecture, bijoux, armes, champs, monnaies, motifs de vêtements ou objets rituels.

Il n'existe pas une règle imposant la même forme à toutes les cultures. Demandez-vous plutôt comment **cette culture** rend visible **cette Rune**.

Une épée peut exprimer la Mort, un motif spiralé le Mouvement, un espace carré la Stase — mais ces associations deviennent intéressantes lorsqu'elles disent quelque chose du peuple, du lieu ou de la Situation qui les porte.

## Pendant une Quête héroïque

Dans l'Autre Monde, les correspondances runiques peuvent devenir beaucoup plus nettes que dans le quotidien. Une couleur peut saturer toute une scène, un corps peut se rapprocher d'une forme mythique, ou un objet révéler brutalement ce qu'il représente.

Une transformation suffisamment importante peut revenir avec le Protagoniste et devenir une nouvelle vérité durable.

## En jeu

L'empreinte runique sert d'abord à **rendre Glorantha visible**.

Quand elle devient importante dans une Situation, elle peut aussi devenir une Mise : une couleur reconnue comme signe d'un culte, une arme dont la forme exprime la Mort, une marque corporelle qui révèle une initiation, etc.

Ne cherchez pas à parsemer chaque description de Runes. Quelques signes significatifs suffisent. Ce qui compte est que les joueurs puissent les remarquer et décider ce qu'ils en font.
