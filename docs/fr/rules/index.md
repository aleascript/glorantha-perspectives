# Règles

Les règles interviennent lorsqu'une Situation contient une véritable incertitude que la table veut jouer.

Le cœur de la résolution reste simple : identifier ce qui compte, construire les Mises, lancer les dés et lire le résultat selon la manière dont le camp concerné habite le monde.

Les chapitres de cette section détaillent les procédures actuellement jouables. Les visions du monde et les particularités gloranthiennes sont présentées directement à partir de leur usage en jeu.
