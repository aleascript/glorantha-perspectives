# Problèmes à clés

Certaines Situations ne consistent pas seulement à vaincre une résistance. Elles demandent de comprendre **ce qu'il faut réellement réunir ou découvrir pour que le problème puisse être résolu**.

Une enquête, une énigme, une fabrication complexe ou une réparation peuvent ainsi être décrites par plusieurs **clés**.

## Définir les clés

Avant ou pendant la Situation, déterminez les éléments nécessaires pour que le problème soit véritablement résolu.

Par exemple, une enquête peut demander de découvrir :

- le coupable ;
- le mobile ;
- le mode opératoire.

Une préparation alchimique pourrait demander :

- un laboratoire utilisable ;
- les bons ingrédients ;
- la recette correcte.

Les clés sont des vérités de la Situation, pas des cases qu'il faut obligatoirement cocher dans un ordre précis.

## Les jouer

Les Protagonistes peuvent obtenir certaines clés directement par leurs choix et leurs recherches lorsque rien ne rend leur acquisition incertaine.

Lorsqu'une véritable incertitude apparaît, utilisez une résolution normale. Le nombre et la nature des clés encore manquantes peuvent alors contribuer à définir l'opposition ou le Facteur Cadre.

Une résolution ne doit pas remplacer la recherche elle-même. Elle tranche ce qui est incertain après que les Protagonistes ont choisi une approche et engagé quelque chose dans la Situation.

## Quand le problème change

Une découverte peut révéler que les clés initiales étaient incomplètes ou mal comprises.

Dans ce cas, changez la description du problème. Glorantha Perspectives ne demande pas de préserver une structure secrète devenue fausse : la Situation évolue avec ce que les Protagonistes apprennent et provoquent.
