# Runes

Les **Runes** sont les formes fondamentales à travers lesquelles Glorantha se laisse lire et agir.

Elles peuvent apparaître dans un Protagoniste, un lieu, une relation, un culte, un objet, un événement ou une Situation. Une Rune peut devenir une **Mise** lorsqu'elle compte réellement dans ce qui se joue ; elle n'accorde jamais automatiquement un avantage.

## En jeu

Les Runes peuvent notamment :

- décrire ce qui est vrai d'un Protagoniste ;
- donner une forme à une magie, une obligation ou une relation ;
- révéler ce qui compte dans une Situation ;
- servir d'appui à une Mise lorsque la fiction le permet ;
- nourrir l'inspiration lorsque le Temps a besoin de faire émerger quelque chose.

Pour utiliser les Runes comme outil d'exploration et d'inspiration, voir [Inspiration runique](./inspiration/).
