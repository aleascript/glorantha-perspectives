# À propos

Glorantha Perspectives est conçu dans le cadre du projet de recherche **Resonance** et utilise **Regard** comme framework de game design.

Le jeu reste autonome : tout ce qui est nécessaire pour jouer doit être expliqué ici. Regard sert de référence pour le framework et ses principes généraux ; Resonance rassemble la recherche de game design plus large.
