# Session 0 — Le Souffle et la Foudre

Cette première séance publiée constitue le **point d'entrée de la chronique d'Edkored**.

Sorane avertit Edkored qu'une patrouille tarshite menace un vieux chaman Kolati. Après avoir détourné les soldats avec la foudre d'Hedkoranth, Edkored suit un signe d'Orlanth jusqu'au lac Still. Il y trouve Vorlak, un jeune Mudhen grièvement blessé, et refuse de le laisser mourir.

La séance s'achève dans une barque, en route vers le crannog caché d'Orstalor Spearlord.

## Quatre façons de lire la session

- [**Verbatim**](verbatim.md) — le jeu dans son ordre réel : échanges Edkored/Temps, Focus, Mises, jets et surenchère.
- [**Récit**](narrative.md) — l'histoire seule, racontée du point de vue d'Edkored.
- [**Coulisses du Temps**](backstage.md) — la structure de la Situation et ce que les résolutions ont rendu vrai, sans publier les fils encore secrets.
- [**Portrait vivant**](portrait.md) — Edkored tel qu'il existe exactement à la fin de cette session.

Les **Coulisses du Temps** révèlent les conséquences de cette séance déjà jouée, mais pas les informations réservées à la suite de la campagne.
