# Préparer un mythe

Un mythe utilisable en jeu doit surtout donner au Temps de quoi préparer des Situations que les Protagonistes pourront réellement traverser.

Avant d'en inventer un, vérifiez si une source de Glorantha fournit déjà un mythe adapté. Une variante locale, une version incomplète ou une interprétation culturelle peuvent souvent être plus intéressantes qu'un récit entièrement nouveau.

## Une structure simple

Pour préparer un mythe, partez de quatre éléments :

1. **Un état du monde** — comment les choses étaient-elles au début ?
2. **Une puissance ou un héros** — qui agit et pourquoi ?
3. **Une difficulté** — qu'est-ce qui menace, manque ou doit changer ?
4. **Une transformation** — qu'est-ce que les actes accomplis expliquent ou fondent dans le monde connu ?

Le mythe peut comporter plusieurs épreuves, rencontres ou retournements. Trois étapes forment souvent une structure facile à retenir, mais ce n'est pas une règle.

## Préparer pour jouer, pas pour réciter

Pour chaque étape, notez seulement ce qui sera utile au Temps :

- ce qui est établi au début de l'étape ;
- les personnes ou puissances présentes ;
- ce qu'elles veulent ;
- ce qui rend l'étape dangereuse ou difficile ;
- ce que les Protagonistes peuvent reconnaître s'ils connaissent le mythe ;
- ce qui pourrait changer s'ils suivent ou quittent le chemin attendu.

Ne préparez pas la décision des Protagonistes. Le mythe donne une forme à la Quête ; il ne décide pas de ce qu'ils feront à l'intérieur.

## Relier le mythe à Glorantha

Un mythe devient plus facile à jouer quand ses éléments ont des effets visibles : une coutume, un lieu sacré, une hostilité ancienne, une propriété d'un animal, un rite, une relation entre dieux ou une manière de comprendre le monde.

Cette continuité permet aux joueurs de reconnaître que ce qu'ils rencontrent dans l'Autre Monde possède déjà des échos dans le monde où vivent leurs Protagonistes.

Certaines Quêtes peuvent aller plus loin que transformer un mythe : elles peuvent conduire un Protagoniste à [**découvrir une nouvelle Vision du monde**](../discovering-a-worldview/), et donc une nouvelle manière pour le réel lui-même de devenir lisible.
