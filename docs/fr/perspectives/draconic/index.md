# Pensée draconique : le Rêve du Dragon

![Dragonewt](/img/runes/dragonewt.png)![Dragon](/img/runes/dragon.png)

Pour un dragonewt, gagner dans le monde matériel n'est pas toujours la meilleure issue. Certains tirages offrent justement le choix entre **forcer le monde** et **s'en détacher**.

Les Mises draconiques utilisent des **D8**.

## Lire le tirage

Chaque dé pair — 2, 4, 6 ou 8 — vaut une réussite ordinaire.

Puis cherchez les **motifs complexes** :

- **Stase de l'Œuf** : plusieurs dés montrent la même valeur ;
- **Ouroboros** : le tirage contient à la fois un 1 et un 8.

Pour chaque motif complexe, le joueur dont le tirage est lu selon la **Pensée draconique** choisit entre **Wyrm** et **Utuma**.

![Dés draconiques](/img/rules/draconic-dice.png)

## Wyrm : agir sur le monde

Le motif complexe devient une réussite supplémentaire pour la résolution.

En échange, le dragonewt s'attache davantage au monde matériel. Ajoutez ou transformez un **Lien** ou une **Attache négative** qui montre ce nouvel ancrage : passion, dette, obsession, possession, honte, désir de domination ou autre conséquence adaptée à ce qui vient de se produire.

Le dragonewt peut gagner ici et maintenant, mais ce choix pèse sur son évolution spirituelle.

## Utuma : renoncer à l'avantage

Le motif complexe ne donne aucune réussite supplémentaire.

Le dragonewt refuse de tordre la réalité pour obtenir une victoire matérielle. Ce renoncement préserve sa progression spirituelle et peut compter dans la manière dont sa prochaine incarnation sera comprise.

L'Utuma n'est donc pas un échec imposé. C'est le choix de ne pas utiliser une puissance disponible.

## Obstacles sans pensée draconique

Lorsqu'un obstacle abstrait est lu avec les règles draconiques par effet de miroir, il ne poursuit pas l'évolution spirituelle d'un dragonewt. Si un motif complexe apparaît dans son tirage, il utilise **Wyrm** : le motif compte comme réussite sans qu'un choix d'Utuma ait de sens pour lui.

## Modes de puissance

### Mode affaibli

Le dragonewt est trop englué dans la matière pour choisir le détachement. Tout motif complexe doit être joué en **Wyrm**, avec les conséquences correspondantes.

### Mode héroïque

La tension entre victoire matérielle et détachement disparaît. Les motifs complexes donnent leurs réussites **et** le dragonewt reçoit le bénéfice spirituel de l'Utuma.

Il peut agir pleinement sur le monde sans s'y attacher davantage.
