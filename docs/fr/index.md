# Glorantha Perspectives

> *En hommage à Greg Stafford, le Grand Chaman qui a le premier percé le Voile pour nous révéler le Plan des Héros. Que son esprit danse éternellement dans le Temps des Dieux, et que ses visions continuent d'inspirer nos propres mythes.*

**Découvrez Glorantha à travers les regards de ceux qui l'habitent.**

Glorantha Perspectives part d'une idée simple : **pour jouer dans Glorantha, regardez d'abord ce qui compte dans Glorantha**.

Les croyances, les liens, les blessures, les lieux, les serments, les Runes, les dieux et les habitudes d'un peuple ne sont pas seulement du décor. Lorsqu'ils deviennent importants dans une Situation, ils pèsent directement dans ce qui arrive.

Vous n'avez pas besoin de connaître toute Glorantha avant de commencer. Le jeu vous invite d'abord à apprendre **où porter votre attention** ; chaque Situation vous donnera ensuite des raisons d'en découvrir davantage.

Le jeu suit des **Protagonistes** qui choisissent leurs intentions et leurs actes. Autour d'eux, le **Temps** fait vivre Glorantha : ses habitants, ses forces, ses contraintes, ses réactions et ses changements. Lorsque l'issue devient réellement incertaine, les **Perspectives** permettent de reconnaître ce qui compte ici et maintenant et de découvrir comment le réel répond.

Vous n'avez pas besoin d'adopter une seule organisation de table. Le Temps peut être porté par une personne, partagé entre plusieurs joueurs, soutenu par des Runes, un oracle ou d'autres outils. Les mêmes règles restent utilisables.

## Par où commencer ?

1. Lisez [Commencer à jouer](start/) pour comprendre le geste fondamental du jeu.
2. Parcourez [Glorantha en quelques repères](start/glorantha) pour apprendre où porter votre regard.
3. Fixez le vocabulaire avec [Protagonistes et Temps](start/vocabulary).
4. Choisissez une [organisation de jeu](start/play-modes).
5. Consultez les [Perspectives](perspectives/) lorsque l'incertitude doit être résolue.

Les chapitres suivants approfondissent ensuite les visions du monde, les Runes, le Chaos, l'Illumination, les Quêtes héroïques et d'autres manières dont Glorantha transforme la résolution.
