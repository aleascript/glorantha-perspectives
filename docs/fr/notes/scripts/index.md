# Scripts — piste de design (WIP)

> Cette note ne fait pas partie des règles publiées de *Glorantha Perspectives*. Elle conserve une piste de game design retirée du Guide afin de pouvoir la reprendre séparément.

## État actuel du Guide

Dans les règles actuelles, **Script** reprend la définition de Regard : c'est un **Zoom large**. Le Focus peut couvrir un voyage, une enquête, une campagne militaire, une négociation prolongée ou un projet complexe.

Un Script fait apparaître davantage de dimensions pertinentes parce que la question posée à la fiction est plus vaste. Il n'ajoute pas, par lui-même, de procédure spéciale.

## Piste retirée

Une version antérieure de *Glorantha Perspectives* donnait au Script une structure supplémentaire :

- le Script était décrit comme une suite d'étapes connues conduisant vers un résultat — par exemple plusieurs épreuves rituelles, une opération préparée, une Quête héroïque structurée par un mythe ou une procédure complexe ;
- les principales étapes étaient nommées avant le tirage ;
- les Mises pertinentes pour traverser l'ensemble du Script étaient réunies dans une résolution unique ;
- si l'issue recherchée par les Protagonistes ne s'imposait pas, le nombre de Réussites pouvait servir à situer jusqu'où ils étaient allés avant que le plan ne rompe ;
- dans certaines Situations, une Réussite pouvait correspondre à une étape franchie ;
- si l'issue recherchée s'imposait, le Script allait jusqu'au bout et la qualité du résultat ainsi que les Mises indiquaient comment.

Cette mécanique n'est **plus canonique**. Elle introduit un comportement propre aux Scripts qui ne découle pas de la définition actuelle du Zoom et doit être redessiné avant toute réintégration.

## À reprendre

L'intention de design derrière cette structure n'est pas abandonnée. Elle doit être reprise dans une conversation dédiée avec l'auteur, en repartant du problème de jeu que ce design cherchait à résoudre plutôt que de considérer cette ancienne implémentation comme un cahier des charges.
