# Mémento

Référence opérationnelle de **Glorantha Perspectives**.

Ce document rassemble uniquement les règles et correspondances qu'il faut pouvoir retrouver rapidement en partie :

- le Grand Cycle de résolution ;
- les Visions du monde ;
- les Influences et transformations ;
- les oracles runiques.

Il ne remplace ni le Guide de jeu, ni Glorantha elle-même.
